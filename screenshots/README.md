# Screenshots

Drop screenshot images in this folder using the filenames below — the root `README.md` already references these paths, so images will show up automatically once added.

| Filename | Screen |
| --- | --- |
| `login.png` | Login / sign-in screen |
| `terminal.png` | POS Terminal (cart + checkout) |
| `invoices.png` | Invoice Register / detail view |
| `closing.png` | Shift Closing (cash reconciliation) |

Recommended: PNG, ~1280px wide, light theme, no real customer/transaction data.
